# Cardápio de Restaurante

## Sobre o projeto

Uma página web que apresenta o cardápio de um restaurante de forma organizada, moderna e fácil de navegar.

A ideia é separar os pratos por categorias e apresentar informações como nome, descrição, preço e imagem de cada item.

## Objetivo

Praticar HTML5 e CSS3 através da criação de uma interface semelhante a um cardápio digital de um restaurante.

Posteriormente, pretendo utilizar JavaScript para adicionar filtros e outras interações.

## Estrutura planejada

1. **Header** — nome/logo e navegação
2. **Apresentação** — apresentação do restaurante
3. **Categorias** — entradas, pratos principais, sobremesas e bebidas
4. **Cardápio** — cards com os produtos
5. **Destaques** — pratos recomendados
6. **Informações** — endereço e horário de funcionamento
7. **Contato** — formas de contato
8. **Footer** — informações adicionais e redes sociais
